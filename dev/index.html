echart-graph-card

Harness URL options
?dark=1Start with the HA dark theme (also toggled by the button)
?only=energy_flow,doorRender only these examples (file names without .yaml)
?live=0No live state updates (static screenshots)
?at=14:00Shift the synthetic data so "now" looks like 14:00 in Europe/Berlin (time axis stays real)
?lang=dehass.locale.language (default en)
?time=12hass.locale.time_format: 12, 24 (default), language, system
?tz=localhass.locale.time_zone = local (default server = Europe/Berlin)
?cols=2 / ?width=520Grid layout: fixed column count / fixed card width in px
?tick=1000Live state update period in ms (default 2000)
?latency=0Maximum simulated WebSocket latency in ms (default 220)
?seed=2Different synthetic data
?stress=1Add a 7-day raw-history card (~120k points per series)
?bundle=1Load the built dist/echart-graph-card.js instead of the sources
?debug=1Log every mock WebSocket call to the console

Console: __harness.setDark(true), __harness.setLive(false), __harness.disconnect(5000), __harness.controller.calls.
